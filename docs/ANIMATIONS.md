# Animations

GSAP anime header, contenu hero et plateau. ScrollTrigger révèle les sections une fois. `prefers-reduced-motion: reduce` désactive les animations et transitions non nécessaires.


Le header est sticky : il se masque lors du scroll descendant et réapparaît lors du scroll montant. Le menu mobile se ferme au démarrage du scroll.
Les barres de progression disposent d’un shimmer continu et les indicateurs LIVE pulsent en boucle. Les animations sont désactivées lorsque `prefers-reduced-motion: reduce` est actif.
